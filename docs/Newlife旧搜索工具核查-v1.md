## 3. 和最新版差别有多大

同一上游插件最新发布为 **v4.4.0，2026-10-10 发布**，其 `package.json` 也标记 4.4.0。[上游发布记录](https://github.com/robbyczgw-cla/web-search-plus-plugin/releases/tag/v4.4.0)、[固定版本清单](https://github.com/robbyczgw-cla/web-search-plus-plugin/blob/v4.4.0/package.json)

| 方面 | 本地 2.5.3 与上游 4.4.0 的主要区别 |
| --- | --- |
| 宿主最低要求 | 旧副本清单的 `minGatewayVersion` 为 2026.4.23；新版为 2026.8.1。本机 2026.7.1-2 高于旧版最低门槛，但低于新版门槛；这只是版本比较，不是运行通过结论 |
| Node 最低要求 | 新版声明 ≥22.22.3；本机 v24.15.0 满足该条件 |
| 输出方向 | 本地有 `web_answer_plus`；上游自 3.x 起移除回答合成功能，转向返回来源结果及正文 |
| 搜索策略 | 新版改变了按查询意图选首个供应商和默认回退顺序；旧配置不能直接假定保留同样的流量及费用分布 |
| 可观察性 | 新版增加研究模式、供应商健康观察、缓存与提取上下文控制等能力 |
| 失败处理 | 新版修复无结果搜索、空白网页提取、批次中单 URL 失败及调用中止传播等情况，减少把失败当成功的风险 |
| 适配方式 | 新版依赖更新的 OpenClaw plugin SDK 入口，不能只看 Node 能运行就判定可直接安装 |

差异依据：[上游固定版本 README](https://github.com/robbyczgw-cla/web-search-plus-plugin/blob/v4.4.0/README.md)、[CHANGELOG](https://github.com/robbyczgw-cla/web-search-plus-plugin/blob/v4.4.0/CHANGELOG.md)。

## 5. 对 API 与费用准备的影响

工具本身和模型 API 是两个层次。若以后在可支持的公开内容整理范围内复用这类插件，通常只需选择一个实际可用的搜索/提取供应商起步，不需要把所有供应商的 API 都购买一遍；模型服务可沿用你已有的服务。

上游代码标记 MIT 许可证，但供应商的查询、提取调用是否收费、是否有赠送额度需要分别看账户与服务条款。**插件代码的许可不等于搜索接口免费，也不等于获得全部平台数据。**本次未选定供应商，因此没有新增付费要求，也没有付费调用。

SearXNG 自建路径与本地浏览器路径也不能仅凭名称判定已部署、零维护或能覆盖目标平台。本次没有启动这些服务。
