# 音乐节兴趣筛选：第一步实施记录

日期：2026-10-29，America/New_York。

当前已获同意的目标是音乐节这一普通兴趣方向。以此记录及项目 README 为当前实施入口；先前亚文化方案、报名分支和跨领域演示不作为本项目的执行要求。

## 已完成

- 在项目内创建独立 `.venv`，Python 3.12.14；首版使用标准库，无外部包依赖，不联网安装。
- 建立可替换的 JSON 模板，音乐节主题词、排除规则、意向分类和排序分均在模板文件中。
- 实现 UTF-8 CSV/JSONL 导入，保留来源平台、内容 ID、作者、原文和链接等约定字段。
- 实现本地规则分类：寻找同行、参加计划、明确喜欢、负面、推广、仅提及和无关。只有模板指定类别进入候选。
- SQLite 分开保存原文版本、模板快照、分析结果和运行批次；重复导入相同版本不重复保存评估。
- 生成只读 HTML 和 JSONL 结果；每条匹配附原文位置和实际引用，页面明确标注演示数据和规则局限。

## 当前限制与下一步

当前是文件输入的规则原型，尚未接社媒平台或模型 API，没有业务采集、密钥使用和付费操作。规则会对反讽、转述、混合意向产生误判，不把排序分当成概率，不把所有匹配内容作者自动视为真实潜在同行。

下一步接入实际可用的数据来源和已有模型服务，补充语义判断。需要先确定首个平台/文件来源，以及模型服务商、Base URL、模型名；密钥通过本机安全方式配置，不放在文档或聊天中。当前没有新增付费需求。
