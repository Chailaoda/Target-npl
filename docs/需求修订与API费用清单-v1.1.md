## 2. API 到底需要哪些

下表说明**可支持的公开内容检索与整理工具**的准备需求，不作为敏感个人识别系统的接入方案。

| 项目 | 是否必需 | 需要提供或确认什么 | 是否需要现在购买 |
| --- | --- | --- | --- |
| 文本模型 API | 使用云模型做内容理解时需要，一个服务即可 | 服务商、Base URL、准确的模型名、接口格式、用量/限额；密钥在本机安全配置 | 不需要另买，先评估你已有的服务 |
| 数据来源/检索接口 | 取决于数据入口；已有可使用文件时不需要 | 对所需公开内容实际可用的接口、导出文件或其他有明确使用权限的数据来源 | 当前不购买；先明确来源和报价 |
| 云 OCR API | 不作为前置 | 本地 OCR 可处理图片中的文字 | 不需要 |
| 图像理解 API | 可选 | 只有文字 OCR 无法满足具体内容整理任务时才评估 | 不需要先买 |
| Embedding / 向量 API | 首版不需要 | 关键词与普通内容分类不必先接向量服务 | 不需要 |
| 搜索型大模型或联网工具 API | 可选 | 可辅助普通网页内容检索；不保证覆盖平台全部帖子或评论 | 不需要先买 |
| 消息推送 API | 首版不需要 | 当前只做本地输出，不接消息渠道 | 不需要 |

**模型 API 与数据入口是两件事。**有模型 API，代表可以让模型理解传入的文本；不代表已经获得平台搜索、评论读取权限，也不代表模型能直接取回所需平台数据。

目前还不知道你已有 API 的服务商和接口信息，因此不能认定已有服务是否自带检索、是否支持图片、是否需要额外计费。先提供服务商、Base URL 和模型名这些非密钥信息即可；密钥不要粘贴进文档或聊天，也不写入代码、命令参数或日志。

## 3. 哪些工作放本机

| 工作 | 建议方式 | 是否消耗模型 API |
| --- | --- | --- |
| 文件读取、文本清理、格式归一 | Python 本地处理 | 否 |
| 关键词、排除词、规则匹配 | 本地规则；相关配置独立保存 | 否 |
| 完全重复检测、内容索引 | 本地计算与 SQLite | 否 |
| 图片文字识别 | RapidOCR + ONNX Runtime CPU | 否 |
| 普通话题分类、复杂歧义理解 | 优先使用你已有的文本模型 API | 是，按实际用量 |
| 报告、来源展示、结果导出 | 本地生成 | 否 |

RapidOCR 官方当前推荐安装 `rapidocr` 和所需推理引擎，不继续以旧的 `rapidocr_onnxruntime` 作为新项目首选。[官方说明](https://rapidai.github.io/RapidOCRDocs/main/install_usage/rapidocr/install/)

本地小语言模型不是前置条件。先用规则和 OCR 处理基础环节，复杂内容再使用现有 API；是否增加本地语言模型，取决于实际任务、显存占用和输出质量，不为了“本地化”先安装大型模型或 CUDA 环境。

【前次已核验】CPU 为 i7-12700H、内存约 40 GiB、GPU 为 RTX 3060 Laptop 6 GiB；当时 E 盘可用约 69.6 GiB，C 盘约 16.3 GiB。这是本会话前次检查的快照，本轮没有重复采集硬件余量。[环境记录](./现场环境核验-v1.json)

【推理】这些资源足以承担上表的本地基础处理。项目放 E 盘、沿用 20 GiB 规划额度，不需要先购买服务器或显卡。本地大模型的速度和质量尚无实测结论。

### 模型费用的可核对算例

以下只是公开内容分类任务的用量算例，不是个人筛选业务报价，也不要求更换你的服务商。

假设处理 1000 条内容，每条调用平均输入 2000 token、总计费输出 300 token，则约使用 200 万输入 token、30 万输出 token。

本次查阅的 DeepSeek 官方人民币价格中，`deepseek-flash` 的非缓存输入为 1–2 元/百万 token，输出为 4–8 元/百万 token，取决于时段。在上述假设下，模型费用约 **3.20–6.40 元**；按 20% 用量余量预算约 **3.84–7.68 元**。[官方模型价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

计算只覆盖上述 token 用量；不含数据接口、搜索/抓取、更多输出、重试超出余量或其他服务。思考输出等若计费，应纳入总输出量。你使用其他服务时，按该服务的实际价格重算，不套用这一金额。

同一官方页面列出的 Search 和 Fetch 标价各为 5 元/1000 次成功请求；这是独立服务，不是必须开通的项目配置。其页面另列有部分工具调用的计费生效时间，若未来选用，按实际入口、日期和账单确认；当前不启用，也不产生这一费用。[官方计费说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

原方案的“100 元模型试验预算”取消作为前置准备要求。已有余额可用时不要求充值；任何新付费都先列明服务、用途、计费方式和预算，再处理购买授权。
