# 火山视频与方舟接入记录

日期：2026-10-29，America/New_York。

## 本轮已落实的约定

- 兴趣方向：音乐节。数据平台：火山视频，未擅自替换为其他社媒平台。
- 模型服务：火山方舟。默认模型：`deepseek-v4-1-flash-261017`（DeepSeek V4.1 Flash 升级 1017）。[官方模型文档](https://console.volcengine.com/ark/region:cn-beijing/docs/deepseek-v4-1-flash)
- 按量 API Base URL：`https://ark.cn-beijing.volces.com/api/v3`。[官方鉴权文档](https://console.volcengine.com/ark/region:cn-beijing/docs/base-url-and-authentication)
- 数据渠道应用级强制直连；模型渠道独立沿用系统策略。没有更改系统代理、环境变量、浏览器配置、其他应用或 WSL。

## 已实现

1. 独立网络客户端：数据请求显式空代理，不读取环境或 Windows 注册表代理；超时失败不回退代理；启用正常 HTTPS 证书验证。
2. 对平台重定向逐跳检查，仅接受已确认官方主机。模型凭证请求不跟随重定向。
3. 火山视频分享页导入入口：只提取具有作品类型标识的公开描述；无数据、客户端壳或验证页明确失败，输出文件不覆盖。尚未适配评论或关键词搜索接口。
4. 方舟 Chat API 分类器：输出类别、逐字原文引用、简短原因；做本地字段和引用检查，保存实际模型 ID 与用量。
5. 模型调用上限：默认每批最多 20 次，输入超限在调用前失败；不自动重试，不自动调用其他模型。
6. Windows 凭据管理器专用条目 `Target-npl/VolcengineArk`；本机隐藏输入，不接收命令行明文密钥，不读取其他应用凭证。
7. 规则与模型结果分开绑定评估身份，避免同一内容的模型结果与规则结果占用同一个存储键。

应用级直连不会绕过已经存在的操作系统级 VPN/TUN。本次没有检查或调整全局路由，不能把“禁用应用代理”表述为已证明物理线路直接出网。

## 实际验证与限制

- 13 项自动检查通过：含原有 7 项与新增 6 项连接检查。新增检查覆盖代理发现隔离、模型网络策略独立、主机/重定向约束、客户端壳不入库、模拟模型引用校验和缺密钥不调用。
- 官网首次探测发现跳转到 `www.huoshanzhibo.com`。核对该主机列于平台[官方用户服务协议](https://lf3-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/huoshan/da595b3c-cdd3-4db7-8031-3402e29005e5.html)后，仅加入这一组官方主机；未放开任意站点。
- 随后使用本项目无代理客户端实际请求 `https://www.huoshan.com/`，返回 HTTP 200，最终地址 `https://www.huoshanzhibo.com/`，内容类型 `text/html; charset=utf-8`。
- **官网连通不等于业务采集成功。**当前 `business_data_verified=false`，没有抓取到真实音乐节作品、评论或候选用户。
- 尚未获得项目专用方舟密钥，没有真实模型调用、余额检查或费用发生；凭证写入/读取的真实账户链路尚待用户本机配置后验证，不能把模拟测试当作账户接通。

## 剩余输入

1. 一条用户所指火山视频的公开视频 HTTPS 分享链接，用来确认作品入口、域名与结构。已在本轮提出请求。
2. 用户在本机交互终端运行 `python -m festival_match configure-ark`（使用项目 `.venv` 解释器）安全配置 API Key；不要把密钥发到聊天。
3. 账户需已开通对应模型；若使用推理接入点 ID，可在配置中填对应 `ep-...`，但需要确认该接入点实际绑定目标模型。

没有因为入口或密钥缺失而改走代理、读取现成浏览器 Cookie、扫描其他软件凭证或购买第三方数据服务。剩余集成依赖上述真实输入，未宣称全链路完成。
