# 源码发布边界

提交内容：通用 Python 引擎、MediaCrawler 适配器、React 控制端源码、CLI/MCP 接口、任务 schema、脱敏离线测试、新建中性配置示例、安装说明和原有第三方许可文件。

不提交内容：原有领域模板、前端个性化预设、个人目标与关键词、历史方案及现场记录、真实内容样本、采集结果、报告、数据库、模型调用回执、任务版本、浏览器状态、Cookie、凭据、API/GitHub Key、原始项目打包和全文转储、虚拟环境、npm 依赖与构建产物。

MediaCrawler 原始代码使用上游仓库和固定版本复现。原有私人工作目录不因发布而清空，运行状态和凭据保留在本机。该仓库是经过脱敏的源码分发版本，不包含原目录的 Git 历史。

后续提交前检查 Git 暂存文件，并运行密钥扫描；`.gitignore` 是排除默认本地文件的措施，不能替代对源码硬编码内容的检查。示例规则是重新编写的虚构测试配置，不是原有个人模板。
